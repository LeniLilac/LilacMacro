# Support

LilacMacro is a volunteer, noncommercial public beta. Support is best-effort and no response time, game compatibility, or unattended-run outcome is guaranteed.

Before opening an issue:

1. Use the newest release from [GitHub Releases](https://github.com/LeniLilac/LilacMacro/releases).
2. Read [Troubleshooting](docs/TROUBLESHOOTING.md) and confirm Windows display scale is 100% on the Roblox monitor.
3. Reproduce with the smallest Plan or setup that still fails.
4. Remove usernames, local paths, private-server links, webhook URLs, credentials, and other personal data.

Use the bug template for a reproducible LilacMacro defect and the feature template for a bounded proposal. Do not attach diagnostics or screenshots unless they are necessary and reviewed for private content. For vulnerabilities or anything containing secrets, follow [SECURITY.md](SECURITY.md) and email privately.

This project cannot provide Roblox, Anime Expeditions, Discord, Windows, GPU-driver, or account-moderation support.
